## Back-translation

**`Pocket Scanner spricht jetzt auch Chinesisch (vereinfacht).`** → *"Pocket Scanner now also
speaks Chinese (simplified)."* Accurate. *Chinesisch (vereinfacht)* is Apple's own German name for
the language, so it matches what a German user sees in iOS Settings. The added *auch* ("also") is
not in the English; it reads more naturally in German and is true, since five languages already
shipped.

**`Einige Beschriftungen, die in anderen Sprachen noch auf Englisch erschienen, sind jetzt
übersetzt.`** → *"Some labels that still appeared in English in other languages are now
translated."* Exact. *Beschriftung* is the right word for a UI label rather than a caption.

**`Pocket Scanner ora parla cinese semplificato.`** → *"Pocket Scanner now speaks simplified
Chinese."* Exact. *cinese semplificato* is the standard Italian name for the language.

**`Alcune etichette che comparivano ancora in inglese nelle altre lingue ora sono tradotte.`** →
*"Some labels that still appeared in English in the other languages are now translated."* Exact.
The imperfect *comparivano* correctly conveys the ongoing past state rather than a single event.
