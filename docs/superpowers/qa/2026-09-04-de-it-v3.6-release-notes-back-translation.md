## The point worth getting right in this release

Paragraph 3 is the one that matters most to a non-English reader, and it is the only paragraph
whose *example* had to change per language. The English says a contract mentioning "receipt" is
no longer filed as one — but the bug it describes was **in that language's own vocabulary**. So
German says *Beleg* and Italian says *scontrino*, each naming the word its own users would have
seen misapplied. Translating "receipt" literally would have described an English-language bug to
a German reader.

That paragraph also carries the localization fix itself: until v3.6, every auto-generated name
was hardcoded English, so a German user scanning a Beleg got *"Rewe Receipt — Sep 4"*. Saying
"the names now appear in your language" is, for these readers, the headline of the release.
