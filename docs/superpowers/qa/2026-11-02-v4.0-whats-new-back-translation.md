## Findings

- **"Wallet-sized" uses each language's usual card-size idiom:** *Scheckkartenformat* (de), *formato carta di
  credito* (it), 银行卡大小 (zh-Hans). A literal "wallet size" reads oddly in all three. Same meaning: an ID-1 card.
- **German avoids the "Seite" repeat.** "Beide Seiten auf eine Seite" (both sides on one page) would use the
  same word twice, so it says "Vorder- und Rückseite auf eine einzige Seite".
- **Italian "tessera"**, not "carta", because "carta" also means paper in a scanner app.
- **UI labels checked by script against `Localizable.xcstrings`:** Page Size, Auto and Scan Document match the
  app in all 8 files (es-MX uses es, fr-CA uses fr).
