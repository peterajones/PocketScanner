## Back-translation

**German, paragraph 1** — *"Your scans now have a real paper size. Set Page Size in Settings to
US Letter or A4, then every scan produces a PDF at a real paper size, exactly as big as documents
from any other source, so they lie neatly side by side. Automatic keeps the shape the scanner
found."*

Exact. *Papiergröße* is the ordinary German word; *Stell … auf* is the informal imperative
matching the app's `du` register, and matching the existing sign-off in the same file.

**German, paragraph 2** — *"Folders can now be created three levels deep, when one level is not
enough for sorting."* Exact.

**Italian, paragraph 1** — *"Your scans now have a real paper format. Set Page Format in Settings
to US Letter or A4 and every scan becomes a PDF with a real paper format, the same size as
documents from any other source, so they sit side by side as they should. Automatic keeps the
shape found by the scanner."*

Exact. *formato carta* is the standard Italian term, and *affiancate* agrees correctly as
feminine plural with *scansioni*.

**Italian, paragraph 2** — *"Folders can now have three levels, for when one level of sorting is
not enough."* Exact.

## Mechanical check results

| Check | Result |
|---|---|
| Character limits, all 7 locales | **PASS** — 485–631 of 4000 |
| Sign-off byte-identical to the shipped v3.4 text | **PASS** — all 7 locales |
| **Cross-reference: notes name controls exactly as the app labels them** | **PASS** — 24/24 |
| Em dashes | **PASS** — none in any locale |
| fr / fr-CA verb families kept distinct | **PASS** — see below |

**The cross-reference check again did the useful work.** These notes instruct the reader to go
and change a setting, so every control they name has to match the app's own label in that
language. Four controls (`Page Size`, `Auto`, `US Letter`, `A4`) across six non-English locales,
all verbatim. Telling a German reader to set "Page Size" would send them looking for a row that
says *Seitengröße*.

**fr-CA is not a copy of fr this time.** It uses the *numériser* family throughout —
*numérisations*, *chaque numérisation*, *le numériseur* — matching the distinction already
established in its subtitle and sign-off, where fr says *scannez* and fr-CA says *numérisez*.
Previous releases could reuse the French body verbatim because it never mentioned scanning; this
one does, in every sentence.
