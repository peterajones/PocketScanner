## Open points for a native reader

- **de "Action-Taste" in the shipped in-app tip** (`Localizable.xcstrings`, the "instant-scan" tip) vs Apple's
  German "Aktionstaste", which the listing uses. The listing follows Apple; the tip may want the same fix.
- **Settings path labels** (Steuerelemente / Controlli / 控制) are Claude's best reading of Apple's localized
  Settings; check against a device in that language if one is handy.
