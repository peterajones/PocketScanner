## Back-translation

| | value | back-translation |
|---|---|---|
| de | Optische Verbesserungen an der App. | *"Visual improvements to the app."* |
| it | Miglioramenti estetici dell'app. | *"Aesthetic improvements to the app."* |

Both exact in sense. German uses *optisch* rather than a literal *kosmetisch*: in German,
*kosmetisch* carries the make-up sense far more strongly than English "cosmetic" does, and
*optische Verbesserungen* is the ordinary phrasing for a visual-only change. Italian *estetici*
is the direct and idiomatic term.

## What this release actually contains, and why the notes do not say so

v3.7 exists because **v3.6 shipped a regression**: the accent tint introduced three days earlier
applies `.tint()` at the `WindowGroup` root, which outranks the default red that
`role: .destructive` provides — so every swipe-to-delete button in the app turned purple.

Peter chose "Cosmetic improvements to the app" over naming the regression. That is a legitimate
call and is recorded rather than argued: the bug is cosmetic, the confirmation alert stayed red
throughout, nobody reported it, and a store listing is not a changelog. The full account lives in
the commit and in this record, which is where it is useful.
